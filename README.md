# VoteLab

This branch packages VoteLab for local team testing. Download the ZIP for Windows x64, macOS Apple Silicon or macOS Intel from the [team test release](https://github.com/qiuliyu1224-jpg/project/releases/tag/votelab-v0.4.1-team-test). Extract the ZIP and follow the included instructions.

See the [VoteLab source and project notes](voting-system/README.md) for features, development setup and tests.

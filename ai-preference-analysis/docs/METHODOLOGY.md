# 方法限制与改进 / Methodology Review

1. **提及不是偏好。**当前规则只检测国内/国外关键词。例如“国产AI不好用”也可能被贴成国产更好。应把品牌提及、偏好立场和情感分别定义，并保留未知/混合类。
2. **情感不能用产品国别代替。**当前ML脚本把支持国产映射为正面、支持国外映射为负面。这只是历史实现，不应作为有效情感金标准。
3. **规则标签不是独立真值。**模型从同一文本的关键词伪标签学习，高分可能只代表复现规则。需建立人工标注集，记录定义、标注者分歧和一致性。
4. **特征拟合范围。**当前TF-IDF在拆分前fit；应先划分训练/验证/测试，再只在训练集拟合，避免词表和IDF信息泄漏。
5. **模型选择。**当前使用测试集挑选最佳模型；应改用验证集或训练集交叉验证选模型，最终测试集只做一次独立评估。
6. **中文表示。**前半段生成了分词结果，但ML仍对未分词clean_text使用默认TF-IDF。应明确使用jieba词序列或字符n-gram，并让训练与预测处理一致。
7. **主题与样本量。**LDA当前使用TF-IDF；建议另构造词频矩阵并评估主题可解释性。固定5主题/4聚类也需由数据支持。
8. **置信度。**无predict_proba时返回1.0不是可信概率，应改为未提供概率，或经独立校准后再报告。
9. **扩展性。**MongoDB先list全部记录、Spark再toPandas、部分模型toarray，都会受本机内存限制；不能称为完整分布式训练。
10. **代表性与隐私。**记录平台、时间、语言、筛选、去重和采样偏差；不得从有限评论直接概括中国用户整体。现有清洗还没有完整的去重或匿名化策略。

以上是静态代码审阅结论；本轮整理没有改变模型方法或重新训练。

# VoteLab 0.4.10 完整示例体验

## 本轮需求与实现

用户确认：首页保留三个分类，一个可操作，两个仅展示。演示和指南互通，图片可放大，入口更醒目；演示操作不进入正式业务记录。

| 需求 | 实现 | 验收依据 |
| --- | --- | --- |
| 明确一个演示与两个展示 | ui4.py 分别标注，入口高 52px、字号 16px | 中英文首页及演示浏览器检查 |
| 作品图片与说明 | 三件作品复用已认可本地素材，含名称、简介、放大、失败提示 | 图片成功/失败、放大关闭、手机不横向溢出 |
| 完整评分流程 | demo.js 选择、核对、返回修改、提交、结果、重来 | 全空阻止；0 分有效；跳过不产生零分；重复提交只产生一个窗口内快照 |
| 演示隔离 | 状态只在窗口内存，不调用业务 POST 或数据库 | 已有正式活动和图片的测试数据库，前后完整业务表快照相同，业务 POST 为零 |
| 指南互通 | 首页、无活动提示、投票指南进入同一演示 | 三件相同作品；指南自由结束；原有未提交评分保留 |
| 展示连接创建说明 | 两个展示说明可打开对应创建指南，用户选择后才去填写页 | 方案模板链接正确；不自动创建或保存 |
| 保留既有能力 | 两处语言、真实投票、审核、反馈、筛选 | 既有界面、新手流程、筛选和程序回归检查 |

## 设计选择

采用可关闭窗口，避免另开页面丢失正式表单选择。指南显示在演示窗口内，Esc 先关闭指南；图片放大时 Esc 先关闭图片。

不在正式选票接口增加演示分支，不预填数据库，因此不会修改正式统计、个人投票记录或导出。结果仅含本次演示评分，没有虚构参与者或预置票数。有效评分的演示平均分分母为 1，跳过不计算平均分。

复用用户已认可的三张素材，减少视觉返工。图片仅作示例，不宣称是实际参赛者提交的作品。图片失败仍能阅读文字。

演示是独立的前端学习流程，不能作为正式服务器验证通过的证据。正式服务由原有测试独立检查；以后更改评分规则，须同时复核演示说明和验收。

报名练习仍是独立表单练习，模拟待审核不代表实际报名或审核。创建指南的链接只打开编辑页，用户保存后才产生正式活动。

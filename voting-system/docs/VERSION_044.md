# VoteLab 0.4.4 第三轮试用反馈

来源：用户本轮明确提出的8项要求，以及选择“接入在线自动翻译服务”的回复。

| 要求 | 实现与验收依据 |
| --- | --- |
| 1 自动发布、权限、统计图 | 新公开活动结束后自动发布；仅自己查看始终限制创建者。柱状、横向柱状、折线图读取同一份结果，邀请码与私密限制不会被图表绕过。旧活动保持手动设置，避免升级公开旧资料。 |
| 2 默认英文 | 无语言Cookie及非法语言Cookie均回到英文；明确选择中文后保留偏好。 |
| 3 邀请码页返回 | 明确返回活动广场，直接打开受限地址也不依赖浏览器历史。 |
| 4 切换账号 | POST和CSRF校验；结束当前会话，进入登录页；旧账号数据及其他设备会话不删除。 |
| 5 英文活动内容 | MyMemory在线显示翻译，包含名称、介绍、公告、审核反馈和统计图标签；输入值、原文、账号身份及选票不改写。失败显示英文状态，提供主动查看原文。 |
| 6 创建页返回 | 创建返回我的活动；编辑返回对应活动。 |
| 7 多数决选数量框 | 只在单／多选中显示、启用数量框；多数决选明确每轮1项，后台仍强制限制。 |
| 8 正式模板措辞 | Activity templates、Custom activity、Entry evaluation、Single-choice voting及对应中文。 |

## 设计判断和边界

- 首轮需要多数决选时，首轮关闭不代表已经产生最终结果。最终发布不能跳过决选。平票或无有效票如实显示状态，不捏造赢家。
- 评分图使用平均分，轴固定0～5，并显示评分人数。未评分和零分分开。RCV图明确同一批排序票的计票步骤，不能暗示每步重新投票。
- 折线图连接作品类别，不宣称时间趋势；不做虚构插值。原始票数和评分始终保留供核对。
- 在线翻译只作为显示，不能改变判断投票是否合法的源数据。缓存按原文匹配，内容修改后不会沿用旧译文。短期签名令牌绑定当前浏览器及会话，不能任意调用翻译代理。
- MyMemory匿名GET额度每日5000字符、每次最多500 UTF-8字节。实现分段、缓存、额度、超时及失败退避。第三方翻译可能出错或不可用；不能宣称永久免费无限使用或离线自动翻译。编辑框仍显示作者原文，避免翻译覆盖原稿。
- 未触及真实用户数据库。自动测试、浏览器检查和在线翻译示例均采用隔离的虚构资料。

## 验证

新增自动发布与图表、导航与正式措辞、翻译缓存和令牌、账号切换和访问控制等回归场景。旧验收场景明确选择中文，以继续检查原语言功能；默认英文另有无Cookie测试。旧手动发布预期按新的明确PUBLIC选项更新，同时保留旧活动迁移及私密访问测试。

本地完整套件99项（源代码副本缺少运行说明时有1项可选说明检查跳过）。独立无界面浏览器走通注册、语言、创建、投票、关闭后结果、图表、返回入口、切换账号及移动布局。在线冒烟仅发送“校园摄影作品评选”等虚构文本。

Windows、Mac Apple Silicon及Mac Intel的发布构建还须通过运行包启动和重启持久化检查，才能发布下载包。构建结果不等于生产级安全或容量认证。

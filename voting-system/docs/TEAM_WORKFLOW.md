# 全组怎样使用同一个GitHub仓库

## 先邀请组员（仓库拥有者操作）

仓库 Settings → Collaborators → Add people，输入每位组员自己的GitHub用户名，对方接受邀请。每个人用自己的账号，不共享密码。当前连接不代表已经邀请了组员。

## 最简单的日常规则

1. 每个人先下载同一版本，按README启动并运行测试。
2. 开始前认领一个具体任务，说明准备修改哪些文件。两个人不要同时改同一个文件。
3. 用自己的任务分支修改，例如 `b2-score-page`；不要直接改主分支。
4. 提交时说明改了什么、对应哪条需求、如何检查；再开Pull Request给组员看。
5. 指定一名整合负责人，检查测试和页面后再合并；其他人再更新本地代码。

Pull Request可理解为“把修改交给小组检查后再合入”。GitHub记录代码不等于网站已上线；大家可下载后在各自电脑本地运行。

## 本次交付

投票系统单独存放在 `voting-system/`，不修改仓库中原有的Spark作业。基础版本先放独立分支供检查。不要上传 `data/` 数据库、真实手机号、密码、验证码、访问令牌或个人课程文件。

# 参考网站与采用内容

查阅日期：2026-11-03。用于理解规则与交互，未复制网页源码、品牌或素材。

| 网站 | 采用内容及边界 |
| --- | --- |
| [W3C WAI — User Notifications](https://www.w3.org/WAI/tutorials/forms/notifications/) | 错误反馈需清楚指出原因与更正方法；本项目突出具体原因并按情境显示入口，去掉通用上传失败模板。 |
| [W3C — Error Identification](https://www.w3.org/WAI/WCAG22/Understanding/error-identification) | 输入错误需识别并描述；用于选票、密码和驳回原因校验，不代表通过完整无障碍审计。 |
| [AEC — School election counting](https://education.aec.gov.au/getvoting/content/instructions-counting.html) | 参考偏好票、过半、淘汰最低者及转票；本项目把提交轮次和内部计票轮区分。 |
| [NSW Electoral Commission — State election counts](https://elections.nsw.gov.au/elections/how-counting-works/how-votes-are-counted-in-a-state-election) | 参考可选偏好耗尽及继续计票分母；本项目显示有效偏好票与耗尽票。最低票并列停止为用户确认规则，并非照搬整个法定选举制度。 |
| [Center for Election Science — Approval Voting](https://electionscience.org/education/approval-voting) | 标准Approval可选任意多个；本项目最多N项属于限额多选，因此用“单／多选”名称。 |

此前用户提供Award Force和SurveyHero作界面讨论参考。本轮平均分、三次修改、邀请码等需求来自用户截图和聊天确认，不声称由参考网站要求。

平均分与评分人数展示是针对可选评分的本项目设计；低样本可能高均分，不声称最公平。是否增加最低评分人数需另行讨论。

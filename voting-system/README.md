# VoteLab / COMP3500

第三版：图片投票、报名审核、验证码登录与中英文界面。Python + SQLite课程原型，单选和0–5评分。AI辅助基础实现，组员需理解、复核并继续开发。

## 启动

安装Python 3.11或更新版本，在本文件夹运行：

```text
python -m pip install -r requirements.txt
python app.py
```

打开 http://127.0.0.1:8000 。这只在运行程序的电脑可访问；GitHub不是在线运行平台。共享演示通过单独的临时服务运行，依赖电脑和网络，非永久部署。

## 登录

一个手机号账号可创建活动、提交作品、投票。界面只有验证码登录/注册，无密码。首次自行注册虚构账号，已有账号直接获取验证码。

**验证码在页面显示，是本地模拟，没有发送短信，不验证手机号归属。**上传演示内容，不使用真实个人信息。仓库不带任何用户数据库，下载者自行注册，原本地演示账号00000001/00000002仅在已初始化的演示电脑存在。旧演示密码不再用于登录。

## 两条完整流程

1. 创建者：创建 → 逐项添加图片/名称/介绍 → 保存预览 → 编辑检查 → 锁定名单开票 → 关闭 → 查看汇总 → 发布结果。
2. 参赛者：创建者允许报名并明确开放 → 普通用户进入活动 → 提交图片/名称/介绍 → 创建者通过/驳回 → 我的作品查看反馈 → 至少两项通过且无待审作品 → 开始投票。

创建者仅管理自己的活动；不能通过选择页面身份获取其他活动权限。开票后不能再改选项或报名。普通选项图片可选；报名作品图片必填。

投票：单选选一项，评分每项明确0–5整数分。先核对再确认，最终检查截止/重复，整张票事务保存。公开结果发布后所有人可看，私密结果仅创建者可看。UI不公开谁投给谁，数据库内部关联不等于密码学匿名。

## 语言与时间

页顶选择中文或English，仅切换界面，不翻译用户内容。截止日期使用UTC+8，当前实现上限30天，可配置，尚待小组确认。投票确认开启时立即开始；定时开始、后台自动任务待做。每次请求及最终提交均检查截止。

## 文件

- app.py：入口、迁移、计票、事务与重复检查。
- web3.py / ui3.py：路由和双语页面。
- entries.py：图片校验保存、结构化选项、报名。
- auth.py：模拟验证码生命周期。
- schema.sql：基础数据表；追加字段由启动迁移保留旧数据。
- static/：图片预览、动态添加移除、语言、搜索和星星评分。
- test_app.py：27项自动测试，独立临时数据库。
- docs/VERSION_3.md：最新范围、实现上限、验证与未完成项。
- docs/VERSION_2.md、PROGRESS_AND_LOGBOOK.md：历史版本记录，不代表最新范围。

```text
python -m unittest -v
```

## 限制

图片支持JPEG/PNG/WebP，5MB以内，重编码去除元数据；待审图片只有提交者和创建者可访问。本轮每活动最多20项，每账号在单一活动限一份报名；参赛者自行修改/撤回/重投尚未实现，需作为后续反馈讨论。

全站管理员、双人审批、延期、奖项分配、平票加赛、PDF导出、多选、决选、真实短信与学号核验、生产安全评审及并发压测仍未完成。不要将课程原型报告为成熟商业平台。

SQLite文件在data/，不上传Git。每个本地运行副本各自存储，临时共享演示使用隔离的虚构数据库。原有其他课程文件不受本项目修改。

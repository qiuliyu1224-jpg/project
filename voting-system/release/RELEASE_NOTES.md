VoteLab 0.4.1 packages the updated VoteLab 04 classroom project for local team testing.

- **Windows x64**. Extract the ZIP and double-click `Start VoteLab.bat`.
- **macOS**. Choose Apple Silicon or Intel in the download name. Extract the ZIP and open `VoteLab.app`. Read the included Mac instructions if Gatekeeper asks you to approve the app.

The program opens in your browser. Use fictional accounts and sample images for testing. Verification codes are displayed on screen. Each computer has its own database, stored in the personal VoteLab data directory outside the extracted folder. The launcher backs up an existing database before startup and reuses it across package updates. A separate copy of the data folder protects against disk failure or accidental deletion.

The test flow creates and reviews an activity, uploads an image, records a rating and checks that data and results are available after restarting the extracted program. Download checksums are in `SHA256SUMS.txt`.

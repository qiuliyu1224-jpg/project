# VoteLab 0.4.11 — Clear voting rules and saved accounts

- Majority runoff is labelled as absolute majority, with a clickable rule explanation.
- Ranked-choice voting has a clickable explanation, including tie and exhausted-ballot limits.
- Optional remembered sign-ins allow account selection within the same browser for up to 30 days. Passwords are not stored in plaintext. Removal, logout and password reset revoke the relevant quick access.
- English and Chinese controls remain on authentication and workspace pages. The user's language choice persists.
- The home page explains that local data is not synced across devices.
- Existing appearance, voting rules, guides, interactive demo and local data tools remain.
- English README contribution entries now exclude presentation work and acknowledge Li Xiaxi's interaction suggestions.

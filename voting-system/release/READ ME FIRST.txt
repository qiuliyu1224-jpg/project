VoteLab 04 - Team Test Release

Windows: Extract the entire ZIP, then double-click Start VoteLab.bat.
macOS: Extract the entire ZIP and open VoteLab.app for your Mac's processor.
VoteLab opens in your browser at http://127.0.0.1:8765/.
Leave VoteLab running while you use the browser. On Windows, press Ctrl+C
in the VoteLab window when you are finished.

Try it
1. Register with a fictional phone account. The demo verification code
   appears on screen. You can use Hong Kong (+852) and 12345678 for testing.
2. Create an activity, add two entries, preview it and open voting.
3. Register a second fictional account to try voting. Check that the vote
   is saved, then use the organiser account to close and publish results.

Your saved data
Windows: %LOCALAPPDATA%\VoteLab\voting.sqlite3
macOS: ~/Library/Application Support/VoteLab/voting.sqlite3
New versions read the same database. VoteLab creates a SQLite snapshot
in the backups subfolder before each startup with an existing database.
Keep a copy of the VoteLab data folder elsewhere if you want protection
against disk failure or deleting the folder. Each computer has its own
activities and votes. Each teammate can test with their own accounts.

If the page does not open, open http://127.0.0.1:8765/ manually. If the
launcher reports that the port is busy, close the earlier VoteLab instance
and launch again. For a second test account use another browser profile
or a private window so the organiser and voter sessions stay separate.

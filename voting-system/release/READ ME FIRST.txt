VoteLab 0.4.5 — 小组试用版 / Team test release

本版修复重复启动时看起来“打不开”的情况

如果旧版已在后台运行，可先在浏览器打开 http://127.0.0.1:8765/ 继续使用。
关闭浏览器页面不会停止 VoteLab。旧程序仍运行时，再次启动旧版可能提示端口已占用。
升级前先退出旧版：Mac 在“活动监视器”中找到已知的 VoteLab 进程并停止；
Windows 在原 VoteLab 窗口按 Ctrl+C 退出。保留原有 voting.sqlite3 和 backups 文件夹。

0.4.5 使用同一用户数据目录。已有 0.4.5 实例正在运行时，再次双击会打开它的现有页面，
不会另建一个服务器、再次迁移数据库或额外生成启动备份。
若占用端口的是无法确认身份的旧版或其他程序，会显示明确错误；不会自动停止其他程序，
也不会自动换端口启动第二个服务器。先核对 http://127.0.0.1:8765/ 所显示的内容。

启动信息和 Python 阶段的启动错误会写入数据目录中的 launcher.log。
Mac 打包程序遇到启动错误时也会显示提示。若错误发生在 Python 运行前，日志可能尚未生成。
本地运行包的资料仍按电脑分别保存；本版没有增加云端共享或 Apple Developer ID 签名与公证。

Version 0.4.5 fixes confusing repeated-launch behavior. If an earlier VoteLab is
already serving, use http://127.0.0.1:8765/ in your browser. Closing the browser
does not stop the local server. Before updating, quit the known old VoteLab
process in Activity Monitor on Mac, or press Ctrl+C in its Windows console.
Keep the existing database and backups.

Opening an already running 0.4.5 instance reopens its current page without a
second server, migration or startup backup. An unverified or unrelated occupant
of the requested port produces an actionable error. VoteLab does not kill that
process or silently switch ports. Startup information and Python-stage failures
are recorded in launcher.log in the same user data directory. The packaged Mac
app also displays startup-error guidance. Failures before Python starts can still
occur before the log exists. Local installations still keep separate data.

通用使用说明 / General operating instructions

Windows x64 请完整解压 ZIP，再双击 Start VoteLab.bat。
Mac 请按芯片选择 Apple Silicon 或 Intel，解压后打开 VoteLab.app。
运行环境已包含在包内。浏览器会打开 http://127.0.0.1:8765/。
Mac 发布构建的原生验证环境为 macOS 15。

1. 选择国家／地区，使用虚构手机号注册测试账号。
   称呼最多60个字符。密码为8～128个字符，注册和重置时两次输入须一致。
   密码未设置必须同时包含字母和数字的规则。
   “显示密码”可自行勾选，默认隐藏。
2. 点击“获取验证码”后在当前页面查看演示码，再填入验证码框。
   获取过程保留已输入的国家、称呼和密码。演示码在页面显示，未发送短信。
3. 创建活动，添加至少两个作品，预览后开始投票。
   用另一个浏览器或无痕窗口登录第二个账号，试用投票，再核对结果。
   首页标注的演示图用于展示样式。活动和结果列表读取实际保存的数据。

多人参与同一场活动时，请大家使用组织者提供的同一在线网址。
本地包在每台电脑上分别保存资料。127.0.0.1 访问的是当前这台电脑。
在同一台电脑上测试多个角色，可使用不同浏览器或无痕窗口分别登录。

账号、活动、图片和选票保存在用户数据目录，更新应用后继续读取原路径。
Windows  %LOCALAPPDATA%\VoteLab\voting.sqlite3
macOS    ~/Library/Application Support/VoteLab/voting.sqlite3
已有数据库启动前会生成 SQLite 快照，位于同一目录的 backups 文件夹。
快照通过 SQLite 完整性检查后保存。另存整个 VoteLab 数据文件夹可用于恢复或换机。
更新前先结束旧版本程序，再解压并打开新版本。

使用时请让 VoteLab 保持运行。Windows 可在 VoteLab 窗口按 Ctrl+C 结束。
Mac 可在“活动监视器”中选择 VoteLab 并停止进程。
页面未自动打开时，可手动打开 http://127.0.0.1:8765/。
提示端口被占用时，请先结束已经运行的 VoteLab，再重新打开。

Mac 包尚未经过 Apple 开发者身份签名和公证。首次打开若受到 Gatekeeper 提示，
确认下载来源后，可按 Apple 的“系统设置 → 隐私与安全性”指引操作。
https://support.apple.com/102445

Windows x64 users should extract the full ZIP and open Start VoteLab.bat.
Mac users should choose Apple Silicon or Intel, extract the ZIP and open VoteLab.app.
The runtime is included. VoteLab opens at http://127.0.0.1:8765/ in your browser.
Native Mac release checks run on macOS 15.

Register with a fictional phone account and the matching country code.
Display names allow up to 60 characters. Passwords allow 8–128 characters.
Registration and reset require two identical entries. There is no letter-and-digit
composition requirement. Show password is optional and starts unchecked.
Get code displays a demo code on the current page while retaining your form entries.
No SMS is sent. Homepage illustrations are labelled examples. Actual activities
and results come from saved data.

For shared voting, everyone should use the same online URL from the organiser.
Each local package has its own database. The address 127.0.0.1 reaches the current
computer. Different browsers or a private window allow separate local test accounts.

Data persists across updates at the Windows or macOS path listed above.
Before startup with an existing database, VoteLab makes a SQLite snapshot in its
backups folder and checks its integrity. A separate copy of the whole data folder
can be used for recovery or moving computers. End the old app before updating.

Leave VoteLab running during use. On Windows press Ctrl+C in its window to stop.
On Mac stop VoteLab in Activity Monitor. If port 8765 is busy, end the earlier app.
The Mac app has no Apple Developer ID signature or notarization. For a trusted
download, follow Apple's first-run guidance if Gatekeeper requests confirmation.
https://support.apple.com/102445


0.4.4：新浏览器默认英文；已有语言偏好会保留。可在顶栏切换账号，不删除旧账号的数据。
新建公开活动在最终轮次结束后自动发布；仅自己查看不公开。旧活动保留原手动发布设置，编辑保存后按新选项执行。
结果页默认显示票数或平均评分，点击生成统计图可选择柱状、横向柱状或折线图。折线连接作品类别，不代表时间趋势。
英文页面的活动名称、作品名及介绍通过 MyMemory 在线翻译，原文和表单编辑内容不改写。翻译需联网，第三方可能译错或限流；失败时显示英文状态并可主动查看原文。
MyMemory 匿名额度为每日5000字符，结果缓存在本机；不会发送密码、手机号、邀请码或选票。不要在活动介绍中填写敏感资料。

0.4.4: English is the default for a new browser; saved language preferences are respected. Switch account ends only the current session and keeps stored records.
New public events publish at the end of the final voting round; private results stay creator-only. Untouched legacy events retain manual publication until explicitly saved with the new policy.
Results show counts or average ratings first; Generate statistics chart offers column, horizontal bar and line charts. Lines connect entry categories and do not imply a time trend.
Chinese activity text is machine-translated online by MyMemory for English display. Original records and editor fields remain unchanged. Network access and provider availability are required; translations may be wrong or unavailable.
The anonymous provider allowance is 5000 characters per day. Successful translations are cached locally. Passwords, phone accounts, invitation codes and ballots are not sent. Do not enter sensitive information in activity descriptions.
Provider documentation: https://mymemory.translated.net/doc/spec.php and https://mymemory.translated.net/doc/usagelimits.php
